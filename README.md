# DA208E (Fall 26) - [Programming in C#, III](https://mau.se/en/study-education/courses/da208e) @ [MAU](https://mau.se/en/)

This is the continuation course of the [Programming in C#, II course (DA205E)](https://github.com/Snicon/DA205E_Programming-in-CSharp-II). In this course we are diving deeper into C# by covering ASP.NET, asynchronous programming, Entity Framework Core and much more. The course consists of multiple assignments grouped into two groups as far as grading goes along with three quizzes.


## Structure

This repo contains all the assignments I've worked on along any other relevant files. For all graded work see the "Graded Assignments" folder. For images of the applications created in the different assignments please refer to the "Application Images", or this readme.



## About assignments

### Assignment 1 - ASP.NET Core Razor Pages
Assignment 1 primarily focuses on making a simple ASP.NET web app with Razor pages, specifically a wedding platform.

The assignment intends to give practical experience with:
- Razor Pages architecture
- PageModels and data models
- Form handling using GET and POST requests
- Model binding
- Input validation using Data Annotations
- HTML, CSS, and Bootstrap
- Managing application data in memory
- Separating presentation logic from application logic
- Bootstrap components
- In-memory data storage
